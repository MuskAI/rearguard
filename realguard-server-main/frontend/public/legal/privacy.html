2. 信息的使用目的

  • 完成账号注册、登录、密码找回、短信校验和访问控制。
  • 处理你提交的图像、视频或文档，生成证据、结论、历史记录和报告。
  • 提供 API Key、额度、计费、幂等重试、任务查询和用量统计。
  • 识别异常流量、排查故障、审计敏感操作并保护不同账号之间的数据隔离。
  • 以随机访客标识统计官网访问量、独立访客和省级来源。登录状态下产生的页面访问可在严格授权的管理后台中与账号关联，用于用户支持和地区运营分析；不会向运营大屏令牌或普通用户公开，可在网站页脚随时关闭后续上报。

3. 模型处理、共享与公开

平台会在自有或受控服务器上处理任务。使用 Swarm 多源复核或其他明确标注的能力时，为完成你选择的任务，文件本身或必要的派生信息可能被发送到平台配置的第三方模型服务；平台只在完成任务所需范围内传输，并通过访问控制、最小权限和审计降低风险。

除获得你的授权、履行法定义务、处理安全事件或完成你主动请求外，平台不会向无关第三方公开或出售个人信息及上传文件。只有你主动创建分享链接时，对应报告才会在链接有效期内向持有链接的人开放。

普通检测记录和公开分享是两件事。默认历史仅当前账号可见；分享必须由用户主动创建，并可撤销。

5. 你的权利与选择

  • 登录后查看个人历史、报告、开发者凭证和用量记录。
  • 删除个人检测历史、撤销分享链接、撤销或轮换 API Key。
  • 在网站页脚关闭访问统计；关闭后不再上报匿名或账号关联页面事件，且不会影响登录、检测或报告功能。
  • 请求更正账号信息，或在完成身份核验后提出个人信息删除和账号处置请求。

当法律规定、争议处理、安全审计或他人合法权益要求保留部分记录时，平台可能无法立即删除全部数据，但会限制其继续用于无关目的。

6. 安全保护与未成年人

平台采用密码和 API Key 哈希、HTTPS、账号级数据隔离、权限控制、CSRF 防护、敏感操作审计以及必要的脱敏措施。没有任何网络系统能够保证绝对安全；发生可能影响用户权益的安全事件时，平台会依法采取补救并在需要时通知。

本服务主要面向具备相应民事行为能力的用户。未成年人应在监护人指导下使用，不应上传包含敏感个人信息或无权处理的他人内容。

7. 联系方式与政策更新

一般产品问题可通过登录后的检测结果反馈功能提交。涉及个人信息更正、删除或账号处置的请求，需要使用对应登录账号完成身份核验。运营主体信息以工信部备案系统中 rrreal.cn 的备案记录为准；独立电子受理邮箱上线后，本页将同步公示。

当数据处理目的、范围或保存期限发生实质变化时，平台会更新版本并通过页面提示；依法需要重新同意的，将在继续处理前再次征求你的确认。
